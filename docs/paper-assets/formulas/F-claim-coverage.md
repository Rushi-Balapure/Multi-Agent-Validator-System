# F-claim-coverage — Claim coverage

**Plan cite:** Research plan §11 / experiment ledger.  
**Every table cell using this metric must cite `run_id` + this formula id.**

## Definition

\[
\mathrm{Coverage} = \frac{\#\{\text{reference claims with prediction or explicit failure}\}}{\#\{\text{reference claims}\}}
\]

Omissions are uncovered, not correct abstentions. Score matched-claim classification separately from extraction coverage.
